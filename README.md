# QuantumPhobia

Paper 서버용 공포증 · 정신병 플러그인. 플레이어에게 공포증을 걸고, 약을 주기적으로 먹어야 버틸 수 있게 만듭니다. 약을 잘못 먹으면 과다복용과 환각이 따라오고, 보이지 않는 **정신병 수치**와 눈에 보이는 **정신력**이 일상의 스트레스에 따라 오르내립니다.

아이템(약 · 진정제 · 진단 키트)과 과다복용 포션 효과는 [QuantumAdders](../Syziege/QuantumAdders)를 통해 추가됩니다.

## 빌드

QuantumAdders를 `provided` 의존성으로 쓰므로, 먼저 QuantumAdders를 로컬 Maven 저장소에 설치해야 합니다.

```bash
cd ../Syziege/QuantumAdders && mvn install
cd ../../QuantumPhobia && mvn clean package
```

`target/QuantumPhobia-0.1.0.jar`을 `plugins/`에 넣고 서버를 재시작하면 됩니다.

## 첫 실행 때 만들어지는 파일

QuantumAdders에는 다른 플러그인이 아이템을 등록하는 API가 없어서, QuantumPhobia가 시작할 때(`onLoad`) QuantumAdders 폴더에 정의 파일을 넣어 둡니다. **이미 있는 파일은 덮어쓰지 않으므로** 이름 · 설명 · 그림은 서버에서 자유롭게 고쳐도 됩니다. 단, 아이템 · 이펙트 id는 바꾸면 안 됩니다.

```
plugins/QuantumPhobia/
  config.yml                      모든 수치 설정
  phobias.yml                     걸려 있는 공포증 (자동 저장)

plugins/QuantumAdders/
  items/quantumphobia.yml         공포증 약 (phobia_cure)
  items/quantumphobia-diagnosis.yml  진단 키트 (phobia_diagnosis_kit)
  items/quantumphobia-sedative.yml   진정제 (sedative)
  effects/quantumphobia.yml       과다복용 1~3단계 포션 효과 (overdose_1~3)
  textures/phobia_cure.png, phobia_diagnosis_kit.png, sedative.png
```

정신병 수치, 정신력, 약 기운, 마지막 복용 시각은 플레이어 데이터(PDC)에 저장돼 재접속 · 재시작 후에도 유지됩니다.

## 명령어

`/qph` (별칭 `/quantumphobia`) · 권한 `quantumphobia.admin` (기본 OP)

| 명령어 | 설명 |
|---|---|
| `/qph give <player> <phobia> [time]` | 공포증 부여. 시간을 생략하면 **영구** (예: `30s`, `10m`, `1h`, `1d`) |
| `/qph remove <player>` | 공포증 제거 |
| `/qph info <player>` | 걸린 공포증과 남은 시간 확인 |
| `/qph insanity <player> [set\|add <값>]` | 정신병 수치 확인 · 설정 (0~100) |
| `/qph willpower <player> [set\|add <값>]` | 정신력 확인 · 설정 (0~100) |
| `/qph list` | 공포증 목록 (플레이어는 GUI) |

아이템은 QuantumAdders 명령어로 지급합니다: `/qa give <player> phobia_cure | sedative | phobia_diagnosis_kit`

## 공포증

현재 공포증은 **정신분열증**(`schizophrenia`) 하나입니다. 공포증이 생긴 플레이어에게는 무엇이 생겼는지 알려 주지 않습니다("무언가에 대한 두려움이 생겨났습니다.").

- **진단 키트** — 우클릭하면 한 개가 소모되고(크리에이티브 제외) 앓고 있는 공포증을 알려 줍니다.
- **약 기운이 없으면 증상** — 공포증이 있는데 약 기운이 떨어지면 "약 기운이 떨어졌습니다."가 한 번 나오고, 그 뒤로 정신병 수치가 매초 오릅니다.

## 공포증 약

약은 공포증을 없애지 않고, 먹은 뒤 **5분 동안 증상만 막아 줍니다**. 약 기운 중에 또 먹으면 시간이 더해지지 않고 처음부터 다시 셉니다. 그래서 미리 여러 개 먹어 둘 수 없고 주기적으로 먹어야 합니다.

| 복용 방식 | 판정 | 효과 |
|---|---|---|
| 정상 복용 | 마지막 복용 후 60초 이상 | 정신병 -10, 정신력 +5 |
| 너무 짧은 간격 | 60초 안에 다시 복용 | 정신병 +10 |
| 과다복용 중 복용 | 과다복용 상태에서 복용 | 정신병 +15 |

## 과다복용

**20초 안에 3번** 먹으면 과다복용이 되고, 과다복용 중에 또 그러면 한 단계 오릅니다(최대 3단계). 과다복용하거나 단계가 오를 때마다 정신력이 20 깎입니다. 끝나면 단계가 초기화됩니다.

| 단계 | 지속 | 정신병 (초당) | 심장박동 간격 | 포션 효과 |
|---|---|---|---|---|
| I | 60초 | +2 | 0.8~3초 | 멀미 |
| II | 90초 | +3 | 0.5~1.8초 | 멀미, 구속 I |
| III | 120초 | +5 | 0.25~1초 | 멀미, 구속 II, 나약함 |

- **심장박동** — 본인에게만 들리는 워든 심장박동이 불규칙하게 뛰고, 가끔 연달아 뜁니다.
- **멀미** — 화면 효과가 제대로 나오도록 한 번에 최소 15초씩 걸립니다. (`period-ticks: 300`)
- **환각 팬텀** — 과다복용 중 정신병 수치가 100이 되면 수치가 0으로 돌아가고 팬텀이 한 마리 늘어납니다. 팬텀이 나타날 때마다 정신력 -5.
  - 본인에게만 보이고, 무적 · 무음이며 아무도 공격하지 않습니다.
  - 10칸 안으로 다가가면 연기와 함께 사라졌다가 5~15초 뒤 다른 곳에 나타납니다.
  - 과다복용이 끝나거나 접속을 끊으면 모두 사라지고, 월드에 저장되지 않습니다.
- **액션바** — `과다복용 II (45s)  |  정신력 ||||||···· 62` 처럼 정신력과 한 줄로 표시됩니다.

## 정신병 수치 · 정신력

| | 정신병 수치 | 정신력 |
|---|---|---|
| 범위 | 0~100, 처음 0 | 0~100, 처음 100 |
| 표시 | 보이지 않음 (관리자 명령어로만 확인) | 바뀔 때 3초간 액션바에 표시 |

정신병 수치가 **오를 때는 항상**:
- 비가 오면 ×1.5, 천둥이 치면 ×2 (월드 날씨 기준)
- 정신력이 일부를 막아 줌 — 정신력 100이면 50%, 50이면 25%, 0이면 막지 못함

### 오르고 내리는 상황

| 상황 | 정신병 | 정신력 |
|---|---|---|
| 정상 간격으로 약 복용 | -10 | +5 |
| 너무 짧은 간격으로 약 복용 | +10 | |
| 과다복용 중 약 복용 | +15 | |
| 과다복용 / 단계 상승 | | -20 |
| 과다복용 중 (매초) | 단계별 +2 / +3 / +5 | |
| 환각 팬텀 출현 | | -5 |
| 약 기운 없는 공포증 (매초) | +1 | |
| 피해를 입음 (1회) | +1 | -1 |
| 잠들기 (1회) | -30 | +40 |
| 진정제 사용 | -15 | +10 |
| 수면 부족 — 3일 이상 안 잠 (매초) | +0.05 | -0.05 |
| 위험한 상황 10초 이상 (매초) | | -0.2 |
| 정신력 30 이하가 60초 이상 (매초) | +0.1 | |
| 정신병 70 이상이 60초 이상 (매초) | | -0.1 |
| 안전한 곳에서 휴식 (매초) | -0.1 | +0.2 |
| 스트레스 없는 상태 60초 이상 (매초) | -0.02 | |

판정 기준:
- **위험한 상황** — 8칸 안에 적대 몹이 있거나 체력 3칸 이하. 환각 팬텀은 적대 몹으로 치지 않습니다.
- **안전한 휴식** — 5초 이상 가만히 있거나 앉아 있고, 12칸 안에 적대 몹이 없고, 밝기 8 이상이고, 10초 동안 피해를 받지 않았고, 과다복용이 아님.
- **스트레스 없는 상태** — 피해 · 위험 · 과다복용 · 수면 부족 · 약 기운 없는 공포증이 모두 없는 상태.
- **잠들기** — 침대에 누운 것만으로는 안 되고 실제로 잠들어야(`PlayerDeepSleepEvent`) 합니다.

모든 수치와 기준은 `config.yml`에서 바꿀 수 있습니다.

## 알아둘 점

- **리소스팩** — 아이템 텍스처는 QuantumAdders가 만드는 리소스팩에 들어갑니다. QuantumAdders `config.yml`의 `pack.java.output`을 ResourcePackManager의 `mixer/`로 지정해 두면 자동으로 합쳐져 배포됩니다.
- **환각 팬텀** — 서버에 실제로 존재하는 몹을 한 명에게만 보이게 하는 방식이라, 다른 플레이어의 화살 등이 보이지 않는 팬텀에 막힐 수 있습니다.
- **날씨** — 월드 단위로 판단하므로 실내나 비가 오지 않는 바이옴에서도 배율이 적용됩니다.
- **정신병 100** — 과다복용이 아닐 때 수치가 100에 도달하면 그대로 멈춥니다(팬텀은 과다복용 중에만 생김).
